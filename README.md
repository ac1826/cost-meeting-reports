# 成本会议报表（每月通用浏览器版）

五张结果表的空白版式已内置在单个app.py中。每月只需上传包含7张来源表的.xlsm工作簿，程序自动创建结果表，不固定9月或任何产品数量。若上传文件已有结果表，会沿用其版式并按产品保留人工填写内容。

## 首次使用

电脑需有 Python，已在 Python 3.12、Streamlit 1.54.0 验证。

在本文件夹打开终端，安装一次依赖：

```powershell
python -m pip install -r requirements.txt
```

以后直接启动：

```powershell
python app.py
```

程序自动打开本机浏览器。终端会显示访问地址，通常是 `http://127.0.0.1:8501`；端口被占用时会自动换一个。请保持终端运行，使用结束后按 Ctrl+C 关闭。

也支持已有的 Streamlit 启动方式：`python -m streamlit run app.py --server.address 127.0.0.1`。

## 操作

1. 在浏览器上传包含7张来源表的 `.xlsm` 工作簿，无需五张结果表。
2. 点击“生成五张表”。
3. 点击“下载结果工作簿”，保存生成的 `.xlsm`。点击“下载生成记录”，保存日志及需要保留的人工内容记录。

结果文件按实际报告期间命名，例如“2026年10月成本会议报表”，不会沿用9月参考文件名。

文件只需包含“列表”“本月”“上月”“上上月”“前三月平均”“负责人填写”“降本目标”这7张来源表，无需附带五张结果表。更换上传文件后，旧的结果下载按钮会清除，需要重新生成。

上传文件只在本机临时处理，处理结束后清理临时文件。下载结果保存在浏览器会话中，关闭或刷新为新会话前请先下载。程序不覆盖原文件，不运行宏，也不把文件发送到云端。

## 每月更新与人工内容

- 把来源数据填回原工作簿对应工作表，保存后上传。本月AE1填写报告期间，例如2609表示2026年9月。
- 负责人和降本目标继续使用关联公式。在“负责人填写”补上姓名后，结果表会随Excel计算更新。“降本目标”继续使用B列物料号、D列目标。
- 下次需要保留工时、差异原因、改善建议和会议纪要时，请上传**已填写并保存过的结果工作簿**。内容按目标表、工厂、物料号和字段匹配。
- 退出清单产品的人工内容另存在生成记录包的CSV中。下载记录包即可保存。
- 7张来源表的名称、表头和列位置需与约定保持一致。已有结果表可选提供；不提供时程序自动套用内置版式。

## 生成规则

### 公式保留方式

- 企划负责人、研发负责人、研发降本目标继续使用关联公式，补上来源姓名或目标后可联动显示。
- 实际减标准、偏差率、边贡率和成本环比保留Excel计算公式。
- 上传模板有“成品偏差额”列时，表头原样保留，并为原有和新增产品生成“产量T×单位成本差额”的公式，延续该模板的计算口径。
- 各月份标准成本、实际成本、前三月平均成本写为可编辑的数值。直接修改结果表中的成本，差额和比例会重新计算。
- 如果修改的是“本月”“上月”等来源表里的成本，请重新上传并生成，以更新结果表的成本数值。

| 目标表 | 产品来源 |
|---|---|
| PFS生产缩小差异 | 列表的渠道为“生产缩小差异” |
| PFS 研发降本 | 列表的渠道为“研发降本” |
| MKA产品 | 列表的渠道为“MKA”，全部生成，负边贡率以红字显示 |
| 观察产品 | 列表的渠道为“观察” |
| 肉松 | 本月工厂为“蚌埠二厂肉松”，排除名称包含“推广包”的产品 |

成本按工厂＋物料号匹配。产量除以1000显示为吨，差额为实际减标准，偏差率为差额除以标准，边贡率为未税单价减成本后除以单价。

产品族内产品个数暂时留空。前三月平均直接使用来源表。缺失数据和分母为0的比例留空并提示。重复键、缺少必要工作表、期间不一致时停止生成并说明原因。

9月样本的验收数量为26、19、29、9、9个产品块，仅用于测试；实际数量每月随清单变化。空类别保留一个无产品的空白版式块，方便下个月重新加入产品。支持10月、1月等换月及跨年，并核对AE1期间的年份与月份。宏和其他工作表保留。查看、重算结果需使用Excel等兼容软件；原生公式验证使用Excel。

## 文件组成

`app.py` 已包含全部计算逻辑，可以独立使用，无需桌面版程序或单独的 engine.py。首次需要安装的依赖记录在 requirements.txt。

五张空白结果表模板已压缩嵌入app.py，无需额外模板文件。源码仓库不包含成本数据，使用时自行准备7张来源表。

## 页面与记录

页面保留上传、生成、产品数量和两个下载按钮。底部“查看提示”“使用说明与生成规则”折叠区已移除。缺失数据等提示仍保存在“下载生成记录”的压缩包中。

## 开发验证

```powershell
python -m unittest discover -s tests -v
```

仓库只包含程序、内置的空白版式、依赖、说明和无业务数据的测试。Excel文件、上传文件、生成结果及本机测试辅助文件通过.gitignore排除。

修改后在项目目录使用git commit和git push同步到仓库；运行中的应用需要重启才能加载新代码。
